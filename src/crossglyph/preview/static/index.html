sizes pt
The reader's Font Size setting lists every size the family carries, one entry each — not the size on the left, which is only what you are tuning at.
second family pt
Sizes here build a second family from the same faces, listed beside this one on the device — the way to give a font eight sizes without one long list. Leave them empty for one family; the suffix is what its name ends with.
coverage Extra Unicode ranges, for books that need them. More coverage means a larger file and a longer build.

Base coverage is in every build first: ASCII and basic Latin plus Unicode punctuation, which keeps letters, numbers, spaces, smart quotes, dashes and ellipses available without adding a language range. What you tick is added on top of it.

Default — the same ranges the fonts CrossPoint ships carry: English, most European languages, Cyrillic (Russian, Ukrainian and so on), combining diacritics, math operators, arrows and common ligatures.

Reading — Default plus the ranges English fiction and popular science actually reach for: broader Latin, Greek terms like λ and φ, box and geometric symbols, supplemental arrows, uncommon dialogue punctuation, CJK quote marks, music notes (♪ ♫ ♬), stars (★) and dingbats (✓).

Arabic — Arabic, Farsi and Urdu letterforms, including the Persian and Urdu letters and presentation forms. Joined rendering depends on the reader's text shaping and not on coverage alone, so isolated codepoints may still draw disconnected.

Where a character comes from: the main family is checked first, then fallback 1, then fallback 2, then the bundled faces. A fallback only fills what is missing — it never replaces a glyph the family already has. Some uncommon codepoints may still be left out of the .cpfont.

None of this decides the page on the left: a preview is built from the text in the box, whatever is ticked here.
